# Vorela Ambientes Planejados

Landing page independente da Vorela, em fase de validação. Não possui relação com APK TEZZEI, HUB SM ou Santa Maria.

## Organização
- `index.html`: página estática e responsiva; a imagem e as demais artes são ilustrações conceituais, não projetos executados.
- `netlify.toml`: publica a raiz do repositório e impede indexação enquanto o nome, o portfólio e o contato são validados.

## Como conectar ao Netlify
1. No painel Netlify, escolha **Add new project → Import an existing project → GitHub**.
2. Autorize apenas o repositório `sergiotezzei-del/Vorela` e selecione-o.
3. Deixe o comando de build em branco e defina o diretório de publicação como `.`; a configuração também está em `netlify.toml`.
4. Use o subdomínio gratuito `.netlify.app`, sem adquirir domínio. O Netlify poderá publicar os commits futuros automaticamente após a conexão.

**Antes de divulgar:** conferir disponibilidade da marca, licença comercial de eventuais fotos, procedimento operacional e telefone WhatsApp; a página ainda não possui número ou depoimentos reais. Verifique o consumo de créditos do plano Free no painel e não habilite recursos pagos.
